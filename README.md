# 🚀 Datalume Decision - Landing Page Futurista (2026 Edition)

Uma Landing Page de vendas moderna, futurista, altamente animada e 100% responsiva (mobile-first) desenvolvida para a plataforma **Datalume Decision**.

---

## 🌟 Recursos e Tecnologias

- **Visual High-Tech & Cyberpunk:** Tema Obsidian Dark com acentos em Ciano Elétrico, Violeta Neon e Esmeralda, efeitos de Glassmorphism, Scanlines e Cyber Grid.
- **Animações Interativas:**
  - **Fundo Dinâmico de Partículas:** Malha de dados conectada por proximidade no Canvas.
  - **Simulador Interativo de Dados (Caos vs Ordem):** Visualização interativa mostrando a transformação de dados caóticos/fragmentados em fluxos inteligentes Datalume.
  - **Contadores de Métricas:** Animações numéricas em tempo real ao rolar a página (+20% Vendas, -15% Custos, 5x Velocidade, 99.8% Acurácia).
  - **Pipeline Interativo de 5 Etapas:** Jornada passo a passo (Conexão, Transformação, Visualização, Análise, Ação) com console HUD dinâmico.
  - **FAQ com Acordeão Fluido:** Abertura e fechamento suaves com ícones e destaques luminosos.
  - **Modal Interativo de Demonstração:** Formulário de alta conversão para captura de leads com validação, estado de carregamento e confirmação.
- **100% Responsivo:** Otimizado para smartphones, tablets, notebooks e telas ultrawide.
- **Cursor Glow:** Efeito magnético de iluminação ambiente para dispositivos desktop.

## ⚡ Como Visualizar a Página

1. Basta dar um **duplo clique no arquivo `index.html`** para abrir diretamente no seu navegador padrão (Google Chrome, Microsoft Edge, Safari, Firefox, etc.).
2. Não requer instalação de dependências ou servidores complexos: tudo roda de forma ultra rápida e nativa.

---

## 🛠️ Personalização Rápida

- **Alterar textos ou depoimentos:** Edite diretamente as tags no arquivo `index.html`.
- **Integrar formulário a um CRM ou Webhook:** No arquivo `app.js`, localize a função `initDemoModal` e adicione a chamada `fetch()` com a URL da sua API ou webhook (ex: Zapier, Make, n8n, RD Station, HubSpot).
- **Ajustar cores e brilhos:** Edite as variáveis CSS no topo de `styles.css`.
